Instrucciones para correr (es preferible primero correr apiserver)
1. Abrir ambos .zip
2. Abrir terminal para cada folder (se corren por separado)
3. Correr `npm i` en ambos para instalar módulos npm
4. Correr `npm run dev` en ambos para correr software
